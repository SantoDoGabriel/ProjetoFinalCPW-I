# 🌐 Projeto Final — Páginas Web I

Este repositório contém o código-fonte do projeto final desenvolvido para a disciplina de **Páginas Web I (CPW-I)** do curso superior de **Tecnologia em Sistemas para Internet** no **IFRS (Campus Porto Alegre)**.

O objetivo do projeto foi construir uma aplicação web funcional, aplicando conceitos fundamentais de desenvolvimento Front-end, estruturação semântica, estilização e interatividade.

---

## 🔗 Links de Acesso

- 🚀 **Aplicação Publicada (Servidor IFRS):** [Acessar Projeto no Ar](https://aula.inf.poa.ifrs.edu.br/~60089684095/CPW-I/ProjetoFinal2/index.html)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de conteúdo.
- **CSS3:** Estilização visual, layout, cores e responsividade.
- **JavaScript:** Manipulação do DOM e lógica de interatividade na página.
- **Servidor Web (Apache/Linux):** Publicação e hospedagem de arquivos no ambiente acadêmico.

---

## 📌 Destaques e Aprendizados

- **Estruturação Semântica:** Uso correto de tags HTML5 para melhoria de acessibilidade e SEO.
- **Estilização Customizada:** Criação de layout próprio utilizando propriedades modernas de CSS.
- **Hospedagem e Deploy:** Processo de publicação de arquivos estáticos em servidor web remoto via transferência de arquivos.
- **Interatividade:** Implementação de scripts em JavaScript para dinamizar a experiência do usuário.
